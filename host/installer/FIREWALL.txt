Setup adds two inbound rules and can add them again. It does not turn the firewall off.

TCP 8765 (or publishPort in host.json) is pairing and telemetry. The rule is named "Xeneon HW Monitor - TCP 8765".
UDP 8764 (or discoveryPort) is discovery. The rule is named "Xeneon HW Monitor - UDP 8764".
Both are limited to the Private and Domain profiles, the local subnet, and XeneonHwMonitor.exe.
Public is not opened.

The settings window shows a warning when those rules are missing. Fix firewall adds them again. The program is already elevated.

Uninstall deletes the rules with netsh advfirewall. An upgrade runs the same script, so the rules are replaced rather than piled up.

Discovery still carries no token. The Pi reconnects with the token it already stored.
